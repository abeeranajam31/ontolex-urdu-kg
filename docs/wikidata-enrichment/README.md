# EMLDS Hindustani lexicographical data on Wikidata

This folder documents the Wikidata Lexeme contribution made for the EMLDS (emergency-domain) Urdu-script vocabulary, and a proposed, source-backed enrichment of it. **Nothing in this folder edits Wikidata.** The proposal is waiting for human review.

## What was contributed

| Step | Count | Record |
|---|---|---|
| Candidate lemmas checked against Wikidata | 193 | `../wikidata_match.csv` |
| Already on Wikidata, same lexical category | 73 | status `exists_same_category` |
| Already on Wikidata, different category | 3 | status `exists_other_category` |
| New lexemes created | 117 | L1732271 to L1732387, `../created_lexemes.csv` |

- **Account and date:** all 117 were created on 29 September 2026 by the account Abxxra, with the edit summary "Urdu lexeme from emergency corpus". The MediaWiki API confirms it created exactly these 117 lexemes and that no one else has edited them since.
- **Language:** Hindustani (Q11051), with an Urdu-script (`ur`) lemma. This is the language item used by the 83 existing lexemes that the candidates matched. The words are treated as Hindustani lexemes written in Urdu script, not as a separate "Urdu" language (Q1617).

## How duplicates were identified

- Each candidate was matched on its Urdu-script lemma and lexical category against existing Wikidata lexemes.
- A candidate was created only when no lexeme had the same lemma and category (status `new`).
- Rows sharing a lemma were merged into one lexeme, unless their part of speech differed. For example, زخمی exists as both an adjective (L1732321) and a noun (L1732322).
- The 76 matches that already existed are listed with their lexeme IDs in `wikidata_match.csv`.

## How the enrichment candidates were selected

The starting point was all 117 lexemes, whose current state was fetched through `wbgetentities` (`raw/lexemes.json`). Each lemma was then looked up in:

- **Platts, *A Dictionary of Urdu, Classical Hindi, and English* (1884; Wikidata Q108916279).** This is the primary source. It is public domain and was read through the DSAL search.
- **Urdu Lughat (Urdu Dictionary Board; Q18625803).** This is the historical dictionary that gives dated quotations. It is the source for Urdu Lughat IDs (P11350) and usage examples. The site blocked this computer's address after 16 lookups, so the remaining lookups are still to do.
- **English Wiktionary.** This was used only to corroborate. It is never the sole basis for a value marked confident.

A lexeme became a candidate if all of the following hold:

1. It is core emergency-domain vocabulary: injuries, medical, fire, crime, hazards, or urgent actions.
2. It has one clear sense in that domain. Homographs such as بس, کار, بو, تار, خانہ and گھسنا were held back.
3. At least one dictionary entry supports that sense.

The result is 50 candidates:

- **Tier A (31):** at least one addition is confident.
- **Tier B (19):** worth enriching, but a key fact needs review first.

The decision for every lexeme, including the 63 that were not selected, is in `audit_117.csv`.

## Enrichment criteria

- **Sense and gloss:** English gloss taken from Platts or Urdu Lughat wording. The Urdu gloss is to be a short paraphrase, not a copied definition. No definition is invented.
- **Item for this sense (P5137):** added only when the item's description matches the sense. Broader or narrower items were rejected. For example, Q9687 "traffic collision" was rejected for ٹکر, and Q1230687, a Polish legal term, was rejected for زخمی.
- **Grammatical gender (P5185):** confident only when two sources agree and none conflicts. Conflicts are flagged: for example, بجلی is feminine in Platts and Wiktionary but masculine in the online Urdu Lughat header.
- **Transitivity (P9295):** taken from Platts, where v.t. means transitive and v.n. means intransitive. The values are Q116946936 and Q116946937, as used by existing Hindustani lexemes.
- **Forms:** direct/oblique × singular/plural, each form carrying grammatical features, which follows Wikidata's lexeme model and the existing lexemes. Forms are generated from the regular paradigm, so they are marked for review rather than as attested. Mass nouns get singular forms only.
- **Pronunciation:** not added. No attested IPA source was reached, and Wiktionary's IPA is generated by a template.
- **Usage examples (P5831):** only verbatim quotations whose source work and year Urdu Lughat names, placed on the matching sense and referenced to Urdu Lughat. Quotations from sources published after 1950 are marked for a licensing check, because Wikidata is CC0.

## How sources were evaluated

| Source | Role | Why |
|---|---|---|
| Urdu Lughat | primary for senses, examples and IDs | Historical-principles dictionary, with each quotation dated and cited |
| Platts (1884) | primary for gender, category and English gloss | Standard scholarly reference, public domain, citable by page |
| Wiktionary | corroboration only | Community-edited; it contradicted itself for الرجی, and gave odd glosses for شدید |
| Urdu Wikisource | checked, not used | Search results were mostly figurative poetry |

## What was intentionally not added

- IPA for any lexeme.
- Gender for زخمی (noun), which has common gender, and for the loanwords, where no dictionary gender was found.
- A P5137 link where no item matches exactly: مدد, چنگاری, گیس, ٹکر and زخمی.
- The medical sense of دورہ, which is not attested yet.
- A sense for either homograph of گھسنا.
- Senses outside the emergency domain for polysemous words (for example بخار "vapour, anger" and تار's 29 senses).

## SPARQL

Run the queries at https://query.wikidata.org/:

1. **`01_contributed_lexemes.rq`:** the 117 lexemes with language, category, and sense and form counts.
2. **`02_category_summary.rq`:** counts by language and category, plus how many lexemes have a sense, gender (P5185) and a Urdu Lughat ID (P11350). On 29 September 2026 it returned Hindustani nouns 75, verbs 21, adjectives 16 and adverbs 5, with 0 in each of the three coverage columns.
3. **`03_senses_and_examples.rq`:** senses, glosses (`skos:definition`), P5137 items, and usage examples on the sense with their P248 source. It returns 0 rows until senses are added.

All three use the RDF model Wikidata publishes for lexemes: `ontolex:LexicalEntry`, `dct:language`, `wikibase:lexicalCategory`, `wikibase:lemma`, `ontolex:sense` and `ontolex:lexicalForm`.

## Reproducing

```
python3 parse_ul.py && python3 parse_refs.py && python3 build.py
```

This uses the cached pages in `raw/`. Re-fetching requires network access, and the Urdu Lughat site may rate-limit.
